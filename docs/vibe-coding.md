# Vibe Coding 开发流程

本次增强运行在本机 CLI。现有三栏布局、样式和编辑器外观不变，也没有新增依赖。

## 从需求定位到交付

1. 绑定项目目录，说明要改什么、哪些文件或行为不能动、通过什么算完成。项目预设可把独立的修改拆给不同开发席位。
2. 模型可用项目导览了解工作区结构，用符号和文本搜索定位代码，再按行读取。搜索可指定子目录，适合 monorepo。符号跳转使用文本启发式，不能保证像语言服务器那样解析重载、别名和同名引用。
3. CLI 在写入前逐文件验证 unified diff、检查旧文件内容以及席位范围。纯格式错误或过时的 hunk 可以给生成方一次重新读文件并修正的机会；它不会把补丁自动移到相似的代码上。删除、锁文件、可执行配置和批量改动仍走确认。若磁盘文件已更新，会在开始应用前重新核对整个写入批次；每一次写入也保留原内容检查。工作区写入不是跨文件事务。
4. 默认使用手动审批，工作项首次执行本地检查前会单独请求授权。可在输入框下方选择「自动审批」，为当前会话自动确认简报、启动工作、继续迭代，并授权当前绑定工作区的检查。切换工作区后需重新授权。需求修订和第 3 步列出的高风险变更需要手动确认。
5. 测试、类型检查和构建只执行可解析的项目检查，不会把任意模型字符串当命令。检查有超时、取消和日志上限；支持提取部分编译器诊断。执行项目脚本本身并非沙盒，只应授权可信项目。没有对应脚本或本地工具时不冒充已执行。

## 模型可用的只读工具

| 名称 | 示例参数 | 结果 |
| --- | --- | --- |
| `project` | `{"path":"packages/web"}` | 清单、主要入口、文档、测试位置和声明的脚本名称 |
| `symbol` | `{"query":"loadWorkspace","path":"src","mode":"definitions"}` | 定义或引用的位置，行列从 1 开始 |
| `read` | `{"path":"src/index.ts","startLine":15,"endLine":50}` | 指定行范围、文件总行数和截断状态 |
| `search` | `{"query":"workspace not found","path":"src"}` | 有界、不区分大小写的文字匹配和行号 |
| `list` | `{"path":"src"}` | 目录条目 |
| `checks` | `{"path":"packages/web"}` | 检查可用性，只做探测、不执行 |

自动读取会避开常见的凭据路径；这不是完备的秘密扫描。把文件作为附件是明确的分享动作，模型供应商会收到该内容。读取和搜索均有范围与大小上限，遇到截断或只返回部分数据时可缩小到更具体的目录或行范围。反复请求相同读取不会无限追加上下文。

## 复杂任务与预置插件

工具名仍放在模型结构化结果的 `tools` 数组中，复用原有的单批、轮次、取消和上下文限制。界面无需操作或改动。

| 名称 | 作用 |
| --- | --- |
| `task_plan` | 添加最多 8 项本次请求的子任务。每项提供 `id`、`title`，可指定 `dependsOn`。依赖必须有效且不可成环；不合法时整批计划不写入。 |
| `task_list` | 读取当前清单及版本号。更新后若要主动查询新快照，在下一批调用。 |
| `task_update` | 按 `id` 更新 `status` 或 `notes`；可带版本号 `revision` 防止过时更新。只有完成依赖才能开始，先进入 `in_progress` 再结束为 `completed`。 |
| `plugin_list` | 列出本地预置插件及可用操作。 |
| `plugin_call` | 如 `{"plugin":"workspace","operation":"overview","path":""}`；只允许目录中预置的工作区导览、符号查找、检查可用性探测。 |

子任务清单可跨当前模型工作循环的多次工具调用读取，开发席位互相隔离。它不单独支持暂停或恢复；取消、切换到新一轮请求或重启后不保留该清单。清单不启动后台进程、不自动并发执行子任务，也不替代原有可恢复的工作项和席位。插件不加载仓库或远程代码，不安装第三方扩展，不访问网络，不执行检查。文件改动和本地检查继续沿既有授权路径处理。

## 验证

```sh
npm ci
npm test
npm run lint
npm run typecheck
npm run build
npm run test:desktop-runtime
```

桌面运行时测试使用本机模拟模型接口，覆盖工作区发现、差异修复、检查授权、失败反馈、多轮自主迭代和 CLI 重启恢复。它不需要真实 API Key；也不替代 Windows 安装包和真实模型供应商实测。
